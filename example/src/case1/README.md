# 택배 상자 꺼내기 문제

## 🎯 문제 설명
1 ~ n의 번호가 있는 택배 상자가 창고에 있습니다. 택배 상자들은 다음과 같은 규칙으로 정리되어 있습니다:

1. 첫 번째 층: 왼쪽 → 오른쪽으로 1번부터 순서대로 w개 배치
2. 두 번째 층: 오른쪽 → 왼쪽으로 다음 번호 순서대로 w개 배치
3. 세 번째 층: 왼쪽 → 오른쪽으로 다음 번호 순서대로 w개 배치
4. 이런 방식으로 n개의 상자를 모두 배치할 때까지 반복

### 택배 찾기 규칙
- 상자를 꺼낼 때는 위에 있는 모든 상자를 먼저 꺼내야 합니다
- 예시: 8번 상자를 꺼내려면 그 위의 20번, 17번 상자를 먼저 꺼내야 함

## ⚙️ 구현 요구사항
특정 번호의 상자를 꺼내기 위해 꺼내야 하는 전체 상자의 개수를 계산하는 함수를 구현하세요.

### 매개변수
- `n`: 전체 택배 상자의 개수 (정수)
- `w`: 한 층에 놓을 수 있는 상자의 개수 (정수)
- `num`: 찾으려는 택배 상자의 번호 (정수)

### 반환값
- 꺼내야 하는 상자의 총 개수를 반환

## 🚫 제한사항
- 2 ≤ n ≤ 100
- 1 ≤ w ≤ 10
- 1 ≤ num ≤ n

## 📝 입출력 예시
| n  | w | num | result |
|----|---|-----|---------|
| 22 | 6 | 8   | 3       |
| 13 | 3 | 6   | 4       |
